# 换电脑与路径配置

本篇用于项目移动目录、Python 路径变化，以及保留原有数据换电脑。所有路径均属于**运行平台的电脑**，浏览器所在电脑不影响这些路径。

只迁移用例、套件和计划定义时，使用 [安装与配置迁移](安装与配置迁移.md) 的 JSON 导入流程。

## 1. 选择处理方式

| 需求 | 操作 |
|---|---|
| 同一电脑移动项目或更换 Python | 编辑原登记，保存新路径 |
| 新电脑只需复用测试定义 | 安装新平台、登记本机资源、导入迁移 JSON |
| 新电脑需保留配置、历史执行、日志和报告 | 停止原平台，复制完整数据目录，再重新绑定路径 |
| 新增另一个项目 | 使用“新增项目”，参照 [新项目登记与执行](新项目登记与执行.md) |

## 2. 移动目录后更新路径

先等待测试结束或取消完成，再打开 **资源与环境 → 管理项目与测试入口**：

| 变化内容 | 在哪里修改 |
|---|---|
| 项目根目录变化 | 项目行“编辑” → 本机项目根目录 → 保存项目 |
| Python 变化 | 运行环境行“编辑” → 本机 Python 解释器 → 保存运行环境 |
| 项目内脚本位置变化 | 测试入口行“编辑” → 项目内相对入口 → 保存测试入口 |
| 视觉脚本或图片目录变化 | 编辑 matcheval 入口的脚本、模板、场景或 Airtest 源码根路径 |
| 已有用例使用旧兼容引用 | 下方“本机路径配置（兼容已有用例）” → 修改对应行 → 保存路径 |

修改原登记可沿用已有引用。整个项目根目录移动、内部结构未变时，通常只需修改项目根目录。

兼容路径配置保存到当前数据库，优先于旧环境变量；留空表示未配置。新项目使用上方的项目与入口登记，不必填写所有兼容路径。

## 3. 保留历史数据换电脑

1. 在原电脑等待执行结束，在启动终端按 `Ctrl+C` 停止平台。
2. 备份完整数据目录，默认为 `platform/data/`；自定义目录以启动终端显示为准。
3. 将平台程序、完整数据目录，以及所需项目源码、资产和配置复制到目标电脑；不复制原平台和项目的 `.venv`。
4. 准备 Python，运行平台的 `install.bat`。平台和项目的虚拟环境均在目标电脑重新创建并安装依赖。
5. 保留目标已有数据的备份，将原电脑数据恢复到目标实例的数据目录，再运行 `start.bat`。
6. 按第 2 节重新绑定项目、Python 和外部资产路径。
7. 在 **资源与环境** 更新被测地址、设备窗口规则、Poco 连接，另行配置密钥引用所需的环境变量或外部密钥。
8. 对资源和计划重新预检，先执行一条小范围测试，再恢复日常使用。

默认数据目录需一起保留：

| 内容 | 用途 |
|---|---|
| `db.sqlite` | 配置、用例、计划、运行和报告记录 |
| `logs/` | 执行日志 |
| `reports/` | 报告文件、截图和其他产物 |

只复制数据库不会带上报告附件。复制前停止平台，可避免复制到不一致的数据。自定义数据目录的启动方式见安装文档；若原来通过 `--db` 指定独立数据库，还需备份该库，并在恢复后指定新位置。

## 4. 核对两种 Python

| 用途 | 在哪里选择 |
|---|---|
| 启动平台 | `start.bat` / `start.ps1` 默认优先使用平台内 `.venv\Scripts\python.exe`，否则使用 PATH 上的 Python |
| 执行测试 | 在网页运行环境中登记，由计划的 Executor 引用 |

需要显式指定启动 Python 时，在 `platform` 目录执行，并将路径替换为实际路径：

```powershell
.\start.ps1 -PythonExe 'C:\Python\python.exe'
```

该 Python 应已安装平台核心依赖。项目依赖应安装在对应测试 Python 中；网页修改测试 Python 不会更换当前平台服务的 Python。

## 5. 更新后检查

1. 项目、运行环境和入口分别点击 **检查配置**。
2. Executor、Environment 分别点击 **预检**；UI 设备按需实时探测。
3. 打开计划核对资源和参数，重新预检并新建执行。
4. 查看新执行的日志和报告，并抽查历史报告附件。

保存路径只验证文件或目录，不能代替依赖检查和业务测试。排队任务发现配置变化时可能拒绝执行，应重新预检并新建执行；历史报告保留原记录。

## 6. 常见问题

| 现象 | 处理方法 |
|---|---|
| 路径存在但检查失败 | 核对文件 / 目录类型；Python 指向 `python.exe`，入口相对于项目根目录 |
| 保存后仍使用错误路径 | 核对实例端口和数据目录，确认修改的是当前实例的配置 |
| 新电脑依赖导入失败 | 在执行机引用的 Python 中重新安装项目及引擎依赖 |
| 被测地址仍指向原电脑 | 编辑 Environment；脚本自行硬编码的地址由项目同步调整 |
| 页面没有更新内容 | 更新后端后重启平台，浏览器按 `Ctrl+F5` 刷新 |
| 删除登记被阻止 | 点击“查看引用”，改用停用；停用、归档和历史记录也可能占用引用 |

删除登记只移除数据库中的配置，不删除本机项目、Python、脚本或素材文件。
